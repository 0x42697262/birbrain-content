== Formula

[latexmath]
++++
P(x|N,K,n) = \frac{\binom{K}{x}\binom{N-K}{n-x}}{\binom{N}{n}}
++++
where:
* latexmath:[N] is the population size
* latexmath:[K] is the number of success in the population
* latexmath:[n] is the sample size
