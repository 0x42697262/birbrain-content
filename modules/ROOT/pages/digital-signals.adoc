In addition to being represented by an analog signal, information can also be represented by a digital signal. For example, a latexmath:[1] can be encoded as a positive voltage and a latexmath:[0] as zero voltage. A digital signal can have more than two levels.

In this case, we can send more than 1 bit for each level.

[NOTE]
====
This figure shows two signals, one with two levels and the other with four.
image::digital-signals-two-digital-signals-one-with-two-signal-levels-and-the-other-with-four-signal-levels.png[]
====

We send 1 bit per level in part (a) of the figure
and 2 bits per level in part (b) of the figure. In general, if a signal has latexmath:[L] levels, each level needs latexmath:[log_2L] bits.

[NOTE]
====
A digital signal has eight levels. How many bits are needed per level? We calculate the number of bits from the formula:
Number of bits per level = latexmath:[log_28=3]
====

Each signal level is represented by 3 bits.

NOTE: A digital signal has nine levels. How many bits are needed per level?

We calculate the number of bits by using the formula. Each signal level is represented by 3.17 bits. However, this answer is not realistic. The number of bits sent per level needs to be an integer as well as a power of latexmath:[2]. For this example, 4 bits can represent one level.
