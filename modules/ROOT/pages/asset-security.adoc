Focuses on digital and physical assets.
This relates to storing, maintaining, retaining, and destroying data.

The second domain of xref:security-domains-cissp.adoc[Security Domains (CISSP)] by xref:certified-information-systems-security-professional.adoc[Certified Information Systems Security Professional].

For example, if a device that contains sensitive information is not properly disposed of, xref:threat-actor.adoc[Threat Actor]s might be able to recover data from it (Computer Forensics).


This domain should focus heavily on these xref:cyberattack.adoc[Cyberattack]s:

* xref:cyber-physical-attack.adoc[Cyber Physical Attack]
