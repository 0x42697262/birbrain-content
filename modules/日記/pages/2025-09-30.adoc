== Windows powershell commands

.Active Directory add new user
----
New-ADUser -Name "Alice Margatroid" `
>> -SamAccountName alice `
>> -UserPrincipalName alice@ad.homelab.com `
>> -AccountPassword (ConvertTo-SecureString "Dolls4us" -AsPlainText -Force) `
>> -Enabled $true `
>> -Path "OU=HR,DC=ad,DC=homelab,DC=com"
----

.Active Directory add new group
----
New-ADGroup -Name HR `
>> -GroupScope Global `
>> -GroupCategory Security `
>> -Path "OU=HR,DC=ad,DC=homelab,DC=com"
----

.Active Directory add user to group
----
Add-ADGroupMember -Identity HR -Members alice
----
